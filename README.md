# 格致 · 数学证明步骤编写与检查工具

一个完全在浏览器运行的数学证明工作台。使用步骤、引用和推理规则组织证明，实时检查结构与符号，并保留版本快照。

## 功能

- 逐步录入前提、推导和结论，选择推理规则并维护步骤引用。
- 检查未定义符号、缺失引用、循环引用和未证明目标。
- 为步骤记录旁注、反例和替代分支。
- 公式快捷输入、KaTeX 实时渲染、原生拖拽排序与键盘导航。
- 文档级撤销/重做，自动保存，多版本文档管理。
- 保存版本快照并进行逐步差异比较。
- 导出 Markdown 或 LaTeX 证明稿。

## 多标签本地稿与合并

在多个浏览器标签里打开同一份证明时，每个标签都是独立的一份本地稿：

- **在线**：编辑实时写入共享基线，标签之间自动同步。
- **断网**：改动只保存在本标签的本地稿（顶栏显示「离线 · 仅本地稿」），不会覆盖其他标签。
- **恢复联网**：各标签基于断网前的共同基线做按步骤三方合并，合并前有短暂等待让其他标签一起上线。
  - 不同步骤的新增、修改、删除全部保留。
  - 同一步骤的**结论、推理规则、依据（引用）**两边都改且不一致时，列入「待处理项」，老师逐项选定后才能生成合并稿；旁注、反例、替代分支等两边都改时并列保留。
  - 一边删除步骤、另一边修改该步骤，同样列入待处理项。
  - 步骤被删除后，所有指向它的引用自动移除，不会留下悬空引用。
- 待处理项处理完成前，编辑、**版本快照**与 **Markdown / LaTeX 导出**都会暂停；它们最终一律使用合并后的结果。
- 顶栏的「模拟断网 / 模拟恢复联网」按钮可用于在同一台机器上演示并核对上述流程。

## 技术栈

- Mithril 2
- TypeScript
- Bulma
- KaTeX
- Vite

## 本地开发

```bash
npm install
npm run dev
```

浏览器打开终端输出的开发地址。数据保存在当前浏览器的 `localStorage` 中。

## 生产构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/Cmd + Enter` | 添加推导步骤 |
| `Ctrl/Cmd + Shift + Enter` | 添加结论步骤 |
| `Alt + ↑ / ↓` | 切换当前步骤 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 立即保存 |
| `Delete` | 删除当前步骤（编辑框外） |

## Docker

镜像内由 nginx 监听容器端口 `80`，不包含或硬编码宿主端口。

```bash
docker build -t math-proof-editor .
docker run --rm -p 10014:80 math-proof-editor
```

宿主端口 `10014` 仅用于本地运行示例，实际编排端口以根端口表为准。
