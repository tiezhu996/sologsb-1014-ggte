# 格致 · 数学证明步骤编写与检查工具

一个完全在浏览器运行的数学证明工作台。使用步骤、引用和推理规则组织证明，实时检查结构与符号，并保留版本快照。

## 功能

- 逐步录入前提、推导和结论，选择推理规则并维护步骤引用。
- 检查未定义符号、缺失引用、循环引用和未证明目标。
- 为步骤记录旁注、反例和替代分支。
- 公式快捷输入、KaTeX 实时渲染、原生拖拽排序与键盘导航。
- 文档级撤销/重做，`localStorage` 自动保存，多版本文档管理。
- 保存版本快照并进行逐步差异比较。
- 导出 Markdown 或 LaTeX 证明稿。
- **多标签协作与断网合并**：每个标签持有独立本地稿，断网期间各自保存互不覆盖；恢复连接时按步骤做三向合并（共同基线 + 两边本地稿），不同步骤的增改全部保留；同一步骤的结论、推理规则或依据两边都改且不一致时列入待处理项，由老师逐项选定后才能继续编辑、存快照或导出。被删除步骤的悬空引用会自动清理，版本快照与两种导出均基于合并稿。

## 本地开发

```bash
npm install
npm run dev
```

浏览器打开终端输出的开发地址。数据保存在当前浏览器的 `localStorage` 中。

## 多标签断网合并

左侧「本地稿与合并」面板展示当前标签身份、连接状态和各标签本地稿。

1. 在两个（或多个）浏览器标签打开同一工作台，标签身份记录在按标签隔离的 `sessionStorage` 中。
2. 点击「模拟断网」（也可直接断网）。断网瞬间各标签冻结同一份共同基线，之后的改动只写入本标签分槽的本地稿，互不覆盖。
3. 在不同标签分别修改、增删步骤并自动保存。
4. 点击「恢复连接并合并」。系统以共同基线做三向合并：
   - 不同步骤的新增、修改、删除全部保留；
   - 同一步骤的**结论、推理规则、依据**若两边都改且不一致，进入待处理弹窗，老师二选一；
   - 一边删除、另一边修改同一步骤时保留修改稿并提示人工确认；
   - 引用自动剔除已消失步骤，杜绝悬空引用。
5. 待处理项全部选定并「生成合并稿」前，编辑、撤销重做、版本快照、Markdown/LaTeX 导出均被锁定。其他标签只读查看，合并完成后自动同步合并稿。

## 生产构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`。

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/Cmd + Enter` | 添加推导步骤 |
| `Ctrl/Cmd + Shift + Enter` | 添加结论步骤 |
| `Alt + ↑ / ↓` | 切换当前步骤 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 立即保存 |
| `Delete` | 删除当前步骤（编辑框外） |

## Docker

镜像内由 nginx 监听容器端口 `80`，不包含或硬编码宿主端口。

```bash
docker build -t math-proof-editor .
docker run --rm -p 10014:80 math-proof-editor
```

宿主端口 `10014` 仅用于本地运行示例，实际编排端口以根端口表为准。
